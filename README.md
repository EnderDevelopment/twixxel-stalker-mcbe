# Twixxel Stalker

Twixxel Stalker is a Minecraft Bedrock Edition horror add-on designed to create a terrifying experience for players. This add-on introduces a unique, original creature called the Twixxel Stalker, which stalks and chases players, creating a suspenseful and immersive horror atmosphere. The add-on includes a custom 3D model, creepy textures, and unsettling animations, along with original ambient and monster sounds to enhance the horror experience. The Twixxel Stalker has balanced movement speed, making encounters survivable, and it sometimes disappears from view, adding an element of unpredictability.

## Install

1. Download the `.mcaddon` file from the GitHub repository.
2. Open Minecraft Bedrock Edition on your Android device.
3. Go to the "Add-Ons" section in the settings menu.
4. Click on the "+" button to add a new add-on.
5. Select the downloaded `.mcaddon` file and follow the prompts to install it.
6. Enable the Twixxel Stalker add-on in the "Add-Ons" section.

## Use

1. Start a new world or load an existing one in Minecraft Bedrock Edition.
2. Ensure the Twixxel Stalker add-on is enabled in the "Add-Ons" section.
3. Explore the world and encounter the Twixxel Stalker.
4. Use normal Minecraft mob behavior to survive encounters with the creature.
5. Enjoy the terrifying and suspenseful horror experience.
